The project is organized as a flat workspace where four child modules share a single `package.json` and are orchestrated by Vite in development and Wrangler/Cloudflare Pages in production. `vite.config.js` injects a dev-only middleware that mirrors the serverless auth/overrides API (`/api/auth/*`, `/api/contribute-path`, `/api/overrides/*`) so the frontend can run locally without Cloudflare Functions; it also proxies external edge services (ETA feeds, Nominatim, OSRM, PMTiles) through `/edge`, `/geocode`, `/osrm`, `/eta/*` with COEP/CORP headers required for the WASM RAPTOR worker. The build pipeline runs Node ESM scripts from `scripts/` via npm lifecycle hooks (`predev`, `prebuild`, `postinstall`) to download MapLibre workers, fare tables, interchange schemes, bus shapes, and open-data artifacts into `public/` and `artifacts/`, which both the frontend app and the static-assets module consume at runtime. `wrangler.toml` declares the Pages deployment target (`pages_build_output_dir = "dist"`) and binds non-secret vars like `OVERRIDES_REPO`; secrets are injected via the Cloudflare dashboard or `wrangler pages secret`. The shared boundary contract between children is the file-based contribution workflow: contributions land as JSON drafts under `artifacts/contributions/pending` (or a sibling `morgan-travelers-overrides` repo), are merged into `public/overrides/bus-shapes.json`, and served identically by the static assets layer and the dev proxy.
