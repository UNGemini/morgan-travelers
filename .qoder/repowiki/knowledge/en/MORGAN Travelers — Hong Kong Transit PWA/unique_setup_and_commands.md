`npm run dev` triggers `predev` hooks that sync MapLibre workers and build fare tables before launching Vite on port 5173; `npm run build` produces the `dist/` directory consumed by `wrangler pages dev dist` or deployed via Wrangler using the `morgan-travelers` project name declared in `wrangler.toml`. Data pipelines are invoked via dedicated scripts such as `npm run build:fares`, `npm run schemes:sync`, `npm run collect:open-data`, and `npm run sync:bus-shapes`.
