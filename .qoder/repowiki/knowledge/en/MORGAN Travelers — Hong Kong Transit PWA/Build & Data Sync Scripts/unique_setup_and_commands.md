Each script is executed directly with Node, e.g. `node scripts/build-fares.mjs`, `node scripts/collect-open-data.mjs [output-dir]`, `node scripts/sync-interchange-schemes.mjs [--detail <id>] [--kmb-route <route>] [--skip-kmb|--skip-citybus]`, `node scripts/summarize-bbi.mjs [--download]`, `node scripts/generate-metadata.mjs [artifacts-dir] [output-path] [public-base-url]`, `node scripts/sync-bus-shapes-from-remote.mjs` (requires `OVERRIDES_BUS_SHAPES_URL`), `node scripts/overrides-local.mjs {status|pending|merge}`. `build-fares.mjs` requires `mdbtools` installed (`brew install mdbtools`) to process TD FARE_BUS/ROUTE/RSTOP MDB files; `collect-open-data.mjs` supports `COLLECT_SKIP_LARGE=1` to skip large artifacts.
