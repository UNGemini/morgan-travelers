Flat collection of independent CLI scripts under `scripts/`, each a self-contained Node ESM module (`#!/usr/bin/env node`) with no shared library — scripts communicate only via JSON files in `public/` (e.g. `public/fares/hk-fares.json`, `public/fares/bbi-compact.json`) and `src/data/interchange-schemes.json`. Two families exist: (1) data collectors (`collect-open-data.mjs`, `sync-interchange-schemes.mjs`, `sync-bus-shapes-from-remote.mjs`, `sync-maplibre-worker.mjs`) that fetch remote CSV/MDB/JSON/GTFS/pmtiles and persist them to `artifacts/` or `public/`; (2) packagers (`build-fares.mjs`, `summarize-bbi.mjs`, `merge-nlb-bbi.mjs`, `generate-metadata.mjs`) that read those artifacts plus local source JSONs and emit compact client bundles. External tooling is invoked via `child_process.execFileSync` (e.g. `mdb-export` for TD MDB files) and optional env-driven URLs (`DATA_PUBLIC_BASE_URL`, `OVERRIDES_BUS_SHAPES_URL`, `COLLECT_SKIP_LARGE`). Each script resolves its root via `fileURLToPath(import.meta.url)` + `path.join(__dirname, '..')` so it can be run from any working directory.
