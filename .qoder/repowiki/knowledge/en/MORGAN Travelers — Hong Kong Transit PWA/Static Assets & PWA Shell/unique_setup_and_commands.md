Service worker cache key is `mtravelers-shell-v11`; bumping it forces old cached shells off devices via `SKIP_WAITING`/`CLEAR_CACHES` messages. Bus shape overrides are maintained in a separate GitHub repo (`morgan-travelers-overrides`) and synced into this bundle with `npm run sync:bus-shapes` or `node scripts/sync-bus-shapes-from-remote.mjs`. The `overrides/README.md` documents the full contribution workflow (PRs to `pending/`, merge script, KV/R2 bindings).
