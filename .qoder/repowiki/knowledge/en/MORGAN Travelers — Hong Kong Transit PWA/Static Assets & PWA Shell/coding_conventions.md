- Hand-maintained corrections live in `public/overrides/*.json` and are never regenerated by the collect pipeline, keeping them separate from auto-generated open-data assets.
- Transit geometry is stored as GeoJSON files under `public/mtr/` and `public/overrides/` using `[longitude, latitude]` coordinate order consistent with GeoJSON spec.
- Per-path HTTP headers in `_headers` pair security policies (COOP/COEP/CORP/nosniff) with cache directives, applying immutable caching only to hashed asset paths like `/src/pkg/*` while keeping HTML and the service worker fresh.
- The service worker deliberately avoids intercepting non-document requests (CSS/JS/WASM) and only implements an offline fallback for navigations, falling back to a cached `/index.html` when network fetch fails.
