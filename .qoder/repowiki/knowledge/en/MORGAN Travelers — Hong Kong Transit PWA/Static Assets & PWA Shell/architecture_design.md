Flat public directory consumed by Vite at build time and served by Cloudflare Pages. Subdirectories group assets by concern: `data/` holds open-data feeds (ETA nearby stops, HK Wheels Router binary, CSV routes/stops); `fares/` contains fare zone and station JSON; `mtr/` provides GeoJSON of stations, platforms, exits, and LRT platforms; `overrides/` stores hand-maintained corrections to open data (bus shapes, LRT pins, MTR access pins) that are merged at runtime against generated datasets; `maplibre/` ships the prebuilt MapLibre GL JS shared and worker modules so the app can run with a fixed version offline. `sw.js` is a minimal service worker that only caches `/index.html` for navigation-only offline fallback and avoids intercepting CSS/JS/WASM to prevent mobile Safari styling issues. `_headers` declares global security headers (COOP same-origin, COEP require-corp, CORP same-origin, nosniff, strict referrer policy) and per-path cache rules (immutable hashed assets under `/src/pkg/*`, no-cache HTML, wasm typed as `application/wasm`, CORS-open API responses). Icons and `manifest.webmanifest` declare the PWA identity (standalone display, maskable icons, dark theme colors).
