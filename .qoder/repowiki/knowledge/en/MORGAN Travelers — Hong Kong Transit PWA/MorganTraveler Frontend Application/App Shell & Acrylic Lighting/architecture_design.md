Three-file leaf that forms the application entry point. `src/main.js` is the monolithic bootstrap: it imports MapLibre GL (with a pinned PMTiles worker URL), basemap layers from `@protomaps/basemaps`, and every domain module (`router.ts`, `geocode.js`, `preferences.js`, `fares.js`, `mtrStations.js`, `eta.js`, `lrtStops.js`, `busShapes.js`, etc.), then builds an `els` DOM cache of all shell elements and runs initialization (acrylic lighting, static overrides, router readiness). `src/acrylic.js` is a self-contained utility that tracks mouse position via `mousemove`/`scroll`/`resize` events, debounces with `requestAnimationFrame`, and writes CSS custom properties `--mouse-x`/`--mouse-y` onto every `[data-acrylic]` element; it also toggles a `mobile-ui` class on `<body>` based on a media query so the effect can be disabled on touch devices. `src/style.css` defines the full design-token system (`:root` variables for colors, radii, safe-area insets, sheet heights), the glass/blur aesthetic, the left-side panel and bottom dock layout, map control positioning, and the acrylic border-glow pseudo-element driven by the JS-updated CSS variables. Dependency direction is one-way: `main.js` imports `acrylic.js` and `style.css`; the two files have no cross-imports.
