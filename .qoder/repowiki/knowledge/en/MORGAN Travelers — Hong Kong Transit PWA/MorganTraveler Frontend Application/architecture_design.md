src/main.js is the single entry point that bootstraps every child module: it initializes MapLibre with PMTiles basemap, loads static overrides, then calls initRouter (routing_engine) which in turn consumes MTR/LRT/GMB domain data (mtr_domain, lrt_gmb_domain), applies post-processing from preferences_and_overrides (alightPrefer, shuttleInject, harbourWalk, stopMerge, geocode), runs fares_and_interchanges on results, and finally feeds routeSnapper/railSnapper + busShapes (eta_service) plus eta.js live ETAs back into the map/UI. Children communicate exclusively through top-level imports in main.js — there is no cross-import graph between sibling modules; each exposes a flat ES-module API consumed by main.js, keeping the domain layers isolated from rendering and routing logic. Shared runtime state (e.g. etaLiveByKey, etaRouteCatalog, pinned routes) lives in main.js as the central event bus between UI, ETA service, and routing engine.
