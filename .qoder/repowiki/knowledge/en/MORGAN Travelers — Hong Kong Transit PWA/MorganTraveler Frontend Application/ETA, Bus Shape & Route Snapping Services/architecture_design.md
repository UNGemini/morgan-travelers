Four cohesive modules under `src/` with a clear separation of concerns:
- `eta.js` is the ETA aggregation layer: it defines a shared in-memory JSON cache (`fetchJson`, 25 s TTL), normalizes timestamps and stop IDs across KMB/Citybus/NLB/MTR/LRT operators via per-operator `fetchXxxEta` functions, merges live arrivals with timetable-derived headway slots (`expandTimetableSlots`, `mergeLiveWithTimetable`, `headwayTimetableSlots`), and produces a uniform `LegEtaResult` shape consumed by the UI. Operator detection is centralized in `etaOperator()` and route short-name helpers.
- `busShapes.js` handles contributor-reviewed bus-route polylines loaded from `overrides.js`. It scores exact route matches (route number + agency + OD name matching) and falls back to geometric corridor matching (`matchSimilarBusShapeOverride`) using haversine-based projection and cumulative-distance scoring; also provides visual-stop overlay and contribution draft submission via `/api/contribute-path`.
- `routeSnapper.js` implements lightweight OSRM-based snapping for bus paths: `projectStops` / `nearestPointOnRoute` project stops onto a LineString with forward bias; `densifyStopsViaOsrm` calls the same-origin `/osrm` proxy for multi-waypoint routing and pair-wise densification; `followRoadsPath` is the contribution-assistant path that never deletes user vertices, only adds road-matched middles via OSRM `match`/`nearest` with drift caps.
- `railSnapper.js` builds an A* graph from Protomaps PMTiles vector tiles at zoom 14, filtering OSM `kind=rail` segments by MTR line code/name preferences, then runs hop-by-hop shortest-path routing between stops with virtual-node splicing, gap bridging, and LRT hard-coded override fallbacks.
Dependency direction is one-way: `eta.js` depends on static data modules (`mtrStations`, `lrtStops`, `preferences`, `mtrColors`); `busShapes.js` depends on `overrides.js`; `routeSnapper.js` and `railSnapper.js` depend only on geometry primitives and external proxies (OSRM, PMTiles). No cross-imports between the four files.
