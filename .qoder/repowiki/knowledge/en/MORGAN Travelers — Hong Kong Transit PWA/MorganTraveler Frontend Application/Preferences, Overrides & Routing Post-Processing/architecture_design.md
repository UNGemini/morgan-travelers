The module is a flat collection of independent ES modules in `src/`, each addressing one routing or UI concern and exposing pure functions plus small data tables. `preferences.js` defines typed enums (`ROUTE_PREFERENCES`, `BUS_COMPANIES`, `TRAFFIC_METHODS`, `SERVICE_DAYS`) with JSDoc typedefs, paired `loadXxx`/`saveXxx` helpers that read/write `localStorage` keys under the `morgan.*` namespace, and classification/formatting utilities for transit modes and Hong Kong service-day clock handling. `overrides.js` caches a single async fetch (`loadStaticOverrides`) that resolves LRT shapes, MTR access pins, and bus-shape routes from a prioritized chain: Vite env URL → same-origin `/api/overrides/bus-shapes.json` (CF proxy) → GitHub raw → bundled fallback; getters expose the resolved objects. `contributePath.js` is the large contributor UI controller: it loads operator-specific stop sequences via the ETA API, merges duplicates through `stopMerge.js`, then selects a path source in priority order (exact published shape → similar shape → rail basemap densifier → OSRM), projects official stops onto the path as visual pins, and wires up a desktop-only editor with undo/redo, box-select, follow-roads preview, and GitHub OAuth/bot submission. `alightPrefer.js` rewrites the last transit leg before destination by scoring candidate alight stops against a destination label using token overlap plus proximity, with hand-maintained route patterns for NLB Tung Chung approaches. `shuttleInject.js` synthesizes missing multi-operator GTFS routes (e.g. S1 circular) by walking to tagged stops within 650 m and building legs with headway-aligned start times. `stationAccess.js` expands origin/destination pins into nearby MTR stations and dual-access complexes (CEN↔HOK, TST↔ETS, AIR↔AWE), then stitches free-link or outdoor walk legs back into plans. `harbourWalk.js` classifies points into island/kowloon/water/out using a lon→lat band table and rejects or heavily penalises cross-harbour walk legs. `geocode.js` implements forward/reverse place search via a same-origin Nominatim proxy, biasing results to Hong Kong bounds and boosting local MTR/LRT directories when queries imply station intent. `stopMerge.js` provides shared stop-deduplication primitives (`mergeStopSequence`, `stopsAreSamePlace`, public-code extraction) reused by contributors and planners.
