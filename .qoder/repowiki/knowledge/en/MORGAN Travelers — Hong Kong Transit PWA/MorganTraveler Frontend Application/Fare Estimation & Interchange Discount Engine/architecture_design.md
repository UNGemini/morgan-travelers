Two-layer module: `src/fares.js` is the computation core that loads a remote `hk-fares.json` matrix (MTR OD, AEL, LRT, MTR Bus) via `initFares()`, normalizes station/stop names, resolves ticket-type mappings (`matrixKeyForType`) to the correct `byId`/`byName` map, and computes per-leg fares plus JoyYou payable amounts. It depends on `interchangeSchemes.js` for MTR bus-bus interchange discounts and on `mtrColors.js` / `lrtStops.js` for line/station classification. `src/interchangeSchemes.js` is a thin data-compiler layer: it statically imports `./data/interchange-schemes.json`, compiles rule arrays into typed `MtrIxRule[]` / `BusBusRule[]` caches, and lazily fetches a separate `fares/bbi-compact.json` for bus-bus discount pairs. Static JSON fixtures under `src/data/` (`interchange-schemes.json`, `nlb-interchange.json`) keep operator-specific rules out of code so they can be edited without redeploying logic. State (active `FareType`, EAL First Class toggle) is persisted in `localStorage` via paired `loadX/saveX` helpers, and all async data loads are deduplicated through module-level `loadPromise` variables.
