Requires Cloudflare Pages environment variables: `GITHUB_OAUTH_CLIENT_ID`, `GITHUB_OAUTH_CLIENT_SECRET`, `GITHUB_OAUTH_REDIRECT_URI` (optional), `OVERRIDES_REPO` (default `UNGemini/morgan-travelers-overrides`), `OVERRIDES_BASE_BRANCH` (default `main`), `OVERRIDES_GITHUB_TOKEN` for bot-mode submissions, and optional `CONTRIBUTIONS_BUCKET` / `CONTRIBUTIONS` KV namespaces plus `CONTRIBUTE_WEBHOOK_URL`. Local development runs through Vite's Pages Functions middleware rather than `wrangler dev`.
